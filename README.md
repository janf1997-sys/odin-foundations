# Odin: Foundations Course 🧱

This repository contains all projects, coding challenges, and exercises completed as part of **[The Odin Project - Foundations](https://www.theodinproject.com/paths/foundations/courses/foundations)** track.

The primary objective of this course is establishing rigorous fundamentals in front-end architecture, modern JavaScript runtime behavior, Git workflows, and semantic web development.

## 🧠 Key Technical Learnings

- **Linux & Tooling (WSL2):** Developing inside a native Linux distribution on Windows via WSL2. Command-line navigation, file permissions, shell scripting basics, and seamless VS Code Remote integration.
- **Semantic HTML5:** Ensuring accessibility, proper tag hierarchy, and SEO-friendly document outlines.
- **CSS Architecture:** Deep dive into the box model, Flexbox axes, specificity management, and clean layout patterns without fragile hacks.
- **Vanilla JavaScript:** Mastering DOM querying, event bubbling/delegation, array methods, and clean functional problem-solving before introducing abstractions/frameworks.
- **Git Discipline:** Atomic commits, descriptive commit messages, and feature-branch workflows strictly managed from the Linux terminal.
